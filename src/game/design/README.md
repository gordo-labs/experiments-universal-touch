## Progresión pedagógica

1. **Game 1:** Aprender los 5 dedos + pinch + toque índice en núcleo.
2. **Game 2:** Exploración FPS + pintar objetos 3D con color de dedo (meta: todo rojo).
3. **Game 3:** Conectar estrellas de color usando solo los índices, evitando cruces entre rayos.
4. **Game 4:** Cargar órbitas elementales y cerrar el núcleo cósmico.
